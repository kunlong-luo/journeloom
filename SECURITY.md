# Security Policy

Journeloom is a local-first personal memory application in planning. Treat all
personal records and media as sensitive, including backups and shared exports.

## Reporting

Please do not file public issues containing personal data, credentials or
reproducible exploits involving someone else's archive. Contact the repository
maintainer privately using GitHub's security advisory reporting if enabled.

## Supported versions

No production release exists yet. No security-support commitment is implied by
the v0.1 design documents.
