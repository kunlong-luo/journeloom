# Journeloom 品牌概念规范 v0.1

## 命名状态

- **英文工作名：** Journeloom。
- **中文工作名：** 岁织。公开网络未发现明显同类软件，但家具商品已使用“岁织”文字，未完成中国商标近似与类别审查。
- **英文 Slogan：** Every Life Has a Story.
- **中文 Slogan：** 每个人的人生，都值得被记录。
- **定位：** Personal Life Timeline & Memory Archive（个人人生时间轴与数字记忆档案）。

截至 2026-10-25，英文名的公开搜索未发现明显同名产品；GitHub 仓库名称搜索未发现同名项目；WIPO 精确文字检索结果为 0 条；`journeloom.com`、`.app`、`.dev` 当时的域名注册查询显示可注册。**这些结果不能证明所有地域、行业类别与近似名称均可安全使用，也未实际注册域名。**

## 品牌性格

温暖但克制、可信而不冰冷、尊重个体、具有时间感、不把人生经历量化打分。坚决避免“人生评分、成功排名、情绪诊断”的宣传语。

## 视觉方向

标志概念：流动的记忆线条交织成打开的书页，表现时间、记录与传承。当前 `assets/journeloom-logo-concept.png` 是 AI 生成的透明背景概念图；正式使用前建议以 SVG 重新绘制，并进行独创性和尺寸适配检查。

### 设计 token（提案）

| Token | HEX | 用途 |
|---|---|---|
| Ink | `#20313B` | 文本、深色标志 |
| Copper | `#C78B65` | 温暖强调、里程碑 |
| Sage | `#7F998B` | 次要状态、自然线索 |
| Paper | `#FAF7F2` | 阅读背景 |
| Surface | `#FFFFFF` | 编辑器画布 |
| Divider | `#DFE4E2` | 分隔线 |

### 字体原则

中英文均优先系统可用的无衬线 UI 字体，长篇人生传记可选择系统衬线字体。避免通过外部字体 CDN 泄露访问信息，保留中英文断行与对比度可访问性。

### Logo 使用

- 横向英文 Wordmark 用于首页与文档封面。
- 书页编织标记独立用作 favicon/PWA icon（需重新设计适配小尺寸的简化 SVG）。
- 背景可以浅纸色或深墨色；不得任意拉伸、加阴影或用于嘈杂照片上。
- Logo 不构成商标登记或独占证明。

## 发布前检查

1. 查询中国商标网、USPTO、EUIPO/WIPO 的精确与近似名称，以及第 9 类、第 42 类等适用服务类别。
2. 核查 App Store、Google Play、GitHub 用户/组织名、目标社交平台句柄。
3. 核对中文“岁织”及其近音、同音、近形注册情况。
4. 再次核查域名可注册和续费价格，确认后由用户亲自授权购买。
