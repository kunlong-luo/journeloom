# Journeloom 产品需求（PRD）v0.1

## 1. 产品定位

**核心价值：** 让个人长期保存可回顾、可解释、可迁移的人生记录。

**第一目标用户：** 愿意持续记录个人经历的成年人；家庭和儿童成长档案为后续方向，v0.1 不开放多人协作。

**用户痛点：** 照片、聊天记录、文档、日记分散在不同设备；人生重大事件容易遗忘，难以按时间整理；分享时容易意外暴露私人信息。

**产品边界：** 不做社交网络、不做健康诊断、不做简历 ATS、不做财务账户聚合、不做云同步、不做自动公开分享。

## 2. MVP 功能（P0）

1. **档案创建：** 显示名、可选出生日期、简介、头像；支持一个或多个本地档案，默认均为私密。
2. **时间轴：** 年/月/日粒度、未知具体日期、跨年月事件；按年份和类别浏览；可编辑、排序、筛选。
3. **人生事件：** 标题、发生时间、地点文本、正文、感受/反思、标签、关联人物、引用来源、媒体附件。
4. **叙事编辑：** Markdown 编辑与即时预览；允许从事件生成个人章节的草稿，但 v0.1 不自动调用 AI。
5. **证据和附件：** 照片、音频、视频及文档的本地引用与元数据；尽量保留文件名、原始日期、SHA-256 校验值。
6. **搜索与筛选：** 关键词、年代、类别、标签、人物。
7. **备份与恢复：** 全量导出为版本化 ZIP（JSON manifest + 附件），恢复前预览并确认；校验文件完整性。
8. **阅读导出：** 导出已筛选事件为 Markdown；浏览器打印为可选 PDF；公开导出必须先经过隐私检查并明确确认。
9. **离线使用：** 安装式 PWA，基础编辑与时间轴无需联网。

## 3. P1/P2 暂不进入第一版

- P1：照片地图、人生章节编辑、家庭关系树、较完整的传记排版、加密备份、导入 Pagevela 职业经历。
- P1：可选本地 Ollama 整理事件与摘要。所有 AI 产出都是草稿，事实、时间和人物需用户确认。
- P2：多设备加密同步、邀请家人协作、精细权限、受控公开页面、纪念册/视频生成、数字遗产管理。

## 4. 首条用户旅程

打开网页 → 新建档案 → 添加“2018 年毕业”事件 → 上传毕业照片 → 写下当时感受 → 在时间轴找到该事件 → 筛选 2015–2020 → 导出一份 Markdown → 生成 ZIP 备份 → 换浏览器恢复并核对。

## 5. 验收标准（必须通过）

- 刷新或离线重启后，本地数据和附件仍可打开。
- 未确定的事件日期不会被系统错误填成具体日期；跨期事件正常显示。
- 事件删除需确认，支持恢复或明确提示不可恢复；可用软删除机制避免误操作。
- 全量备份与恢复的事件数量、内容、附件 SHA-256 校验结果一致。
- 公共导出中，私密内容和原始附件默认不包含；用户可以逐项预览。
- 不会向分析服务、第三方 API 或仓库提交私人记录、附件、文件名和分享数据。
- 桌面与手机视口可用；键盘操作、焦点顺序、颜色对比度符合常见无障碍要求。
- 自动化测试覆盖创建、编辑、刷新、备份/恢复、敏感信息排除和离线访问。

## 6. 重要风险

- 浏览器存储可能被用户清除或因容量压力被回收：首次记录后就提示定期导出，备份不是可选奢侈功能。
- 家庭/儿童/第三人称内容可能涉及隐私、肖像与争议性经历：公开分享前需脱敏预览，不默认为公开。
- AI 可能虚构事件、人物动机或时间：任何生成文本要标注草稿来源，不能静默修改史实。
- 不应让 GitHub 充当私人照片库或敏感档案数据库。
